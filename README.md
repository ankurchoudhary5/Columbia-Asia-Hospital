# Columbia-Asia-Hospital

📊 Columbia Asia Hospital Analysis – Power BI Project
📌 Project Description
-Analyzed Columbia Asia Hospital’s operational and patient data to understand performance across departments, services, and patient segments.

-Prepared and validated the dataset using Power Query by handling missing values, fixing data types, and standardizing demographic fields.

-Created a structured data model and developed essential DAX measures for KPIs, aggregations, and dynamic filtering.

-Designed a multi-page Power BI dashboard covering revenue trends, patient volume, wait-time metrics, department activity, and doctor-level analysis.

Used SQL for initial data exploration and Power BI for modeling and visualization.
